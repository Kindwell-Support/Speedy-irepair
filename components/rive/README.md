# components/rive

There are no `.riv` assets yet. Every icon is a **code-driven SVG behind the same state API** (approved). Real files drop into `public/rive/` later; then run `pnpm rive:manifest`.

| File | Role |
|---|---|
| `manifest.ts` | `RIVE_ICONS` (15 ids: C1–C8 home + S01–S14 services) and `RIVE_ALIASES` (Design `icon-repair` …). `resolveRiveIcon()` returns `{ id, art, riveSrc?, stateMachine }`. `.riv` contract: state machine `State Machine 1`, inputs `hover` (bool) and `press` (trigger; `click` alias). |
| `available.generated.ts` | Generated by `scripts/gen-rive-manifest.mjs`. The set of `.riv` files actually present (currently empty). |
| `RiveIcon.tsx` | `<RiveIcon id size label? hover? />`. Host = closest `[data-rive-host]` / `[data-rive]`; its hover, focus and click drive the state. Mounts Rive (dynamic, IO-gated, wasm self-hosted at `/rive/rive.wasm`) only if a `.riv` exists, otherwise uses the SVG with an `m.g` accent (hover scale 1.12, y −1; click spring pulse). Sets `data-rive-icon`, `data-rive-mode`, `data-state`. |
| `RiveCanvas.tsx` | Lazy `useRive` renderer + state machine inputs. |
| `RiveLoader.tsx` | `role=status` loader. Uses `loader.riv` if present, otherwise a skeleton shimmer (`ShimmerBar`). Never a spinner (Design rule). |
| `RiveButton.tsx` | `state="idle\|loading\|success\|error"`. Press scale .97, a shimmer sweep while loading, an sr-only live status, and success/error swaps. |
| `icons.tsx` | SVG art (base + accent layers) for the 15 icons. |

Under reduced motion Rive is never mounted and no wasm is fetched.
